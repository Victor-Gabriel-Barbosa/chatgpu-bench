# chatgpu-bench

Script para executar testes no ChatGPU e salvar os resultados em arquivos JSON.

## Como baixar e executar

Requisitos: Windows, Python instalado e navegador Brave instalado.

1. Clone o repositório e entre na pasta:

   ```powershell
   git clone https://github.com/Victor-Gabriel-Barbosa/chatgpu-bench.git
   cd chatgpu-bench
   ```

2. Crie e ative um ambiente virtual:

   ```powershell
   python -m venv .venv
   .\.venv\Scripts\Activate.ps1
   ```

3. Instale as dependências:

   ```powershell
   python -m pip install -r requirements.txt
   ```

4. Inicie o script:

   ```powershell
   python main.py
   ```

5. Quando solicitado, escolha a pasta onde os resultados serão salvos.

O script controla o mouse e o teclado para interagir com o navegador e o Gerenciador de Tarefas. Deixe o computador livre durante a execução.
